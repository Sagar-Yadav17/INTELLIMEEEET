A full-stack real-time meeting and collaboration platform built using the MERN stack. IntelliMeet allows users to create meetings, collaborate in real time, manage tasks, and communicate efficiently through a modern web interface.

---

## 🚀 Features

- 🔐 User Authentication using JWT
- 📹 Real-time meeting and collaboration support
- 💬 Real-time communication using Socket.IO
- 📝 Task management functionalities
- 👥 User-friendly dashboard and UI
- 📂 MongoDB database integration
- ⚡ Responsive frontend built with React + Vite
- 🌐 REST API integration using Express.js
- ☁️ Separate frontend and backend deployment
